# Models Directory

This directory is intended to store the trained model files.

## How to use
1. Train the model using `notebooks/02_training.ipynb` (e.g., on Kaggle or Google Colab).
2. Download the saved model file `fruit_model.h5` (or `.keras`).
3. Place the file in this directory: `fruit-recognition/models/fruit_model.h5`.

The Streamlit app will automatically detect and load this model.
